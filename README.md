# Site da ABEAA — versão de teste

Site da Associação Bandeirante de Engenheiros, Arquitetos e Agrônomos de Santana de Parnaíba (ABEAA).

- O site é gerado automaticamente pelo GitHub a cada mudança ("Publicar site").
- O robô "Notícias" busca, todo dia, as notícias do CREA-SP e do Confea.
- Enquanto a variável SITE_OFICIAL não for "sim", o site sai como TESTE (faixa amarela e fora do Google).
